## 📖 Présentation

Ce dépôt sert d'hôte de téléchargement et de point de distribution pour les assets, les manifests de version et les fichiers exécutables consommés par le **[La-Guerre-Des-Capsules-Launcher](https://github.com/nexos20lv/La-Guerre-Des-Capsules-Launcher)**.

---

## 📁 Structure du Dépôt

```
├── manifest.json       # Fichier JSON décrivant la dernière version du jeu et la liste des fichiers
├── assets/             # Bundles d'images, sons et ressources additionnelles
└── releases/           # Binaires compilés (.exe, .zip) des différentes versions du jeu
```
